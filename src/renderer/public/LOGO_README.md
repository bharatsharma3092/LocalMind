# Brand logo assets

Drop your logo image(s) here. They are shown in the app **exactly as authored**
(no redraw, no compression) and override the built-in SVG fallback.

| File | Used for | Recommended |
|------|----------|-------------|
| `localmind-logo.png` | Full logo (sidebar brand) | wide PNG, transparent or its own background |
| `localmind-mark.png` | Optional square "LM" mark for compact spots | square PNG (e.g. 256×256) |

After adding/replacing a file, just reload the app (`npm run dev`) — no code changes needed.

The OS application icon is separate. Replace these in the repo's top-level `resources/` folder:
`icon.png`, `icon-512.png`, `icon-256.png` (square PNGs), and `icon.ico` (multi-size ICO for the Windows installer).
